# YouTube workflow

Published or controlled draft article → verify structured claims, unresolved issues and rights records → generate complete JSON and Markdown video plan → human factual review → collect or create visuals → rights review → write narration → record → edit → final factual review → publish manually → record performance later.

The website article remains authoritative; a video must not be less accurate. Phase 2 may add optional Search Console, YouTube Data API, manual competitor metadata and public-interest discovery without transcript copying. Phase 3 may review views, impressions, CTR, average view duration, 30-second retention, traffic sources, website clicks and article visits to adjust scoring.
