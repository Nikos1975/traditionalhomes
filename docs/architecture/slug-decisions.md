# Slug Decisions

## Demetra / Dimitra

`demetra` is the proposed canonical slug.

`dimitra` is suspected legacy spelling.

No migration has been performed yet. Do not rename `dimitra` or `demetra` paths, data keys, images, content, or URLs as part of Phase 1 hygiene work.

Before any future migration, list all references first. That reference list should include routes, content collections, inventory data, gallery data, location data, contact forms, image folders, public URLs, docs, redirects, generated output, and any external references that may already be indexed or shared.

If public URLs existed for the old spelling, the migration must preserve those old URLs with redirects or another explicit compatibility strategy.
