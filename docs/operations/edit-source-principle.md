# Edit-Source Principle

Supporting Layer 3 operations reference. It routes no task, owns no facts and grants
no permission. Routing stays `CLAUDE.md` -> `CONTEXT.md` -> one workspace -> one stage.

## Rule

EDIT SOURCE != EDIT DERIVED OUTPUT.

Configure the factory, not the product. A defect visible in a generated product is
repaired in the source that produces it, then regenerated through the existing
derivation path. Hand-editing a derived product to hide a source defect is forbidden,
even when the edit would look correct in the product.

## Classification

Before editing, classify the requested artifact as exactly one of:

- **Authoritative source** — the single owner of a fact or contract. Editing it is the
  only way to change that fact.
- **Authored source** — human-written material that is not generated from anything else
  (prose, contracts, documentation, tests, configuration).
- **Derived / generated output** — produced by an existing script, build step or
  integration from an upstream source. Never the repair surface for its own source.
- **Local evidence** — untracked records of what a run observed. Never repository state.
- **Build / cache artifact** — regenerable output of a build or tool cache. Never an
  edit source, never a fact source, and not part of a reviewed change.

## Decision Procedure

1. Classify the target artifact.
2. Identify the owning workspace and stage through the existing router.
3. Identify the exact authoritative or authored edit source for the requested change.
4. Identify the existing derivation mechanism, if the target is derived.
5. Constrain the change to the exact files that are allowed to change.
6. Edit the source.
7. Regenerate through the existing mechanism only when the task authorizes it.
8. Verify the derived output as evidence that the source edit worked.
9. Stop at every review, approval and permission gate.

## Fail-Closed Rule

If the edit source, its owner or its derivation mechanism cannot be established
confidently: STOP AND REPORT. Do not patch the product, do not guess a generator and
do not invent a source relationship to make the request actionable.

## Representative Repository Examples

- Property facts: `src/inventory/inventory.json` is the authoritative source. Property
  pages, presentation mappings and translated presentation data consume those facts and
  never become an alternative fact source. A wrong bedroom count is fixed in the
  inventory, not in the rendered page.
- Content-intelligence inventories: `data/content-intelligence/inventory.json` and
  `data/content-intelligence/inventory.md` are generated by `npm run content:inventory`
  (`scripts/content-intelligence/cli.mjs`) from the repository's content. Their source is
  the content those runs read, not the generated files. They are also the two protected
  working-tree modifications recorded in `docs/handoff/current.md`: do not stage, revert
  or regenerate them without an instruction naming them.
- Local ICM provenance: `scripts/context/icm-run.mjs` writes records beneath the
  untracked `.agent/icm/` directory. That material is local evidence only. It is never an
  edit source for repository state and never authority.
- Build and cache output: `dist/` from `npm run build` and tool caches are regenerable
  build artifacts. They are never edited, never staged and never cited as fact.
- Sitemap output: the sitemap is produced at build time by the `@astrojs/sitemap`
  integration configured in `astro.config.mjs` from the routes the build emits. Route and
  configuration sources own it; the emitted sitemap is verification output.

## No Second Source of Truth

This is a routing and editing method, not a registry. It creates no factual authority,
no workflow authority and no file-ownership database, and it does not duplicate or
override existing owners. Property facts, Search Console performance evidence, routed
editorial research inputs, the English factual master and its routed i18n resources, the
social publication ledger and the operations-deployment contracts remain exactly as their
own owners define them. The method tells an agent how to find and respect those
authorities.

## Permission Boundary

Identifying an edit source is not permission. It never authorizes merge, push, force
push, deployment, Cloudflare mutation, publication or social publication. Regenerating a
derived output is not deployment, and a correct derived product is not approval.
