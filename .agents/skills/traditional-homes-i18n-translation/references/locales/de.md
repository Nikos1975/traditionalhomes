# German Reference

Load only for German localization work.

## Public terminology already established

- houses / collection: `Ferienhäuser`
- house: `Haus`
- location: `Lage`
- guide: `Reiseführer`
- breadcrumbs accessibility label: `Navigationspfad`
- Crete: `Kreta`

Proper names remain unchanged unless an established German form exists: Elounda, Mavrikiano, Vrouchas, Spinalonga, Argyro, Margarita, Erato, Monastiri and other property names.

## Style

Use natural contemporary German suitable for independent travellers researching accommodation and place context.

Prefer direct practical wording over literal translation. Avoid inflated tourism vocabulary and compound constructions that read like machine translation.

## Reference implementation lessons

The German visible-language completion established these presentation patterns:

- `Ground floor + first floor` → `Erdgeschoss + Obergeschoss`
- `Internal stairs` → `Innentreppe`
- `Shower room` → `Duschbad`
- `Shared Guest Parking` → `Gemeinsamer Gästeparkplatz`
- `Mrs. Olga` → `Frau Olga`

These are examples of presentation, not factual sources. Always derive the fact from its English/structured source first.
